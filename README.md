# ✅ Task Manager

A simple and responsive **Task Manager** built with **HTML, CSS, JavaScript, and Bootstrap 5**. It helps you organize tasks, set deadlines, assign priorities, and manage your daily work.

## ✨ Features

- ➕ Add new tasks with a title, description, date, and priority
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔎 Search tasks by title or description
- 🎯 Filter tasks by priority (High, Medium, Low)
- 📊 Automatically sort tasks by priority (High → Medium → Low)
- 💾 Save tasks in the browser using `localStorage`
- 📱 Responsive layout for smaller screens
- 🎨 Clean, nature-inspired green and cream design

## 🛠️ Technologies Used

- **HTML5** — page structure
- **CSS3** — styling and responsive design
- **JavaScript** — task management, search, filtering, sorting, and events
- **Bootstrap 5.3.8** — layout and form/table styling
- **Browser Local Storage** — saves tasks between page refreshes

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser.

   You can also open the folder in **Visual Studio Code** and run it using the **Live Server** extension.

## 🧭 How to Use

1. Enter a task title and description.
2. Select a due date and priority.
3. Click **Add task**.
4. Use **Search tasks** to find a task by its title or description.
5. Choose a priority from the filter dropdown to show matching tasks.
6. Click **Edit** to update a task, or **Remove** to delete it.

## 💾 Data Storage

Tasks are saved in your browser's `localStorage`, so they remain available after refreshing the page in the same browser. The tasks are stored locally on your device and are not synced to a server. Clearing the browser's site data may remove them.

## 🎨 Design

The interface uses a soft cream background, deep green text, white cards, and muted green accents for a calm, minimal look. The task table and form adjust for smaller screens.

## 📌 Notes

- The project includes a few sample tasks when no saved tasks exist.
- Task priority is sorted automatically: **High**, **Medium**, then **Low**.
- This is a front-end learning project; it does not use a backend or database.
